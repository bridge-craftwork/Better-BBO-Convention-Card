Getting started

  1. Turn the extension on in Safari’s settings, under Extensions.
  2. In Bridge Base Online’s web lobby, open Account, then Convention cards.
  3. Click the extension’s button in Safari’s toolbar and choose Always Allow on This Website. Safari asks once for each of Bridge Base Online’s two sites, the lobby and the card list, so allow both.
  4. Reopen Convention cards. Import from PDF or JSON appears beside New ACBL Convention Card, and each card has Print, Save PDF and View buttons.

Until Safari allows it on Bridge Base Online, the extension shows nothing, and its toolbar button is grey. You can also allow the sites in Safari’s settings: Extensions, then Edit Websites…
